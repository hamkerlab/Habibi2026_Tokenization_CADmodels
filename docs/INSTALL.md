# Installation
The installation of cad-transformer is super easy.

If you would like to install it to an existing PyTorch environment, just jump to **step 3**. 

**Step 1:** Create an python environment for cad-transformer
```shell
conda create --name cad-transformer python=3.11.10 -y
conda activate cad-transformer
```

**Step 2:** Install the required packages
```shell
pip install -r requirements.txt
```

**Step 3:** Clone the codebase: 
```
# Clone cad-transformer codebase
git clone https://gitlab.hrz.tu-chemnitz.de/hsay--tu-chemnitz.de/cad-transformer.git
```

Then you are all set.
